# Salus (Milestone 3)

Run it on a computer (Windows, Mac or Linux) with Node.js installed, and view it on your Android phone with the Expo Go app.

1. Install Node.js (LTS) from nodejs.org. Install "Expo Go" on your phone from Google Play.
2. Open a terminal INSIDE this folder.
3. Run these, one at a time, and wait for each to finish:

       npm install
       npm run setup
       npm start

4. Scan the QR code with Expo Go. Phone and computer must be on the same Wi-Fi.
   If it will not connect, stop and run:  npx expo start --tunnel

`npm run setup` installs the right library versions for the current Expo Go automatically.
